# SBO v3.0 통합 고객 상담 조회 & 실시간 상담일지 DB 연동 시스템

SBO 메인 DB(원본 100% 읽기 전용)와 치과 전용 DB(원본 100% 읽기 전용)를 결합하고, **김은미 부장님 요청에 따른 '실시간 전화상담 메모 저장 및 AI 일정/병원 자동 분석'** 기능을 완전 구축한 공식 v3.0 시스템입니다.

---

## 🚀 v3.0 핵심 업데이트 내역
1. **메인 DB & 치과 DB 원본 100% 읽기 전용(Read-Only) 연동**:
   - 원본 시트(메인DB, 치과전용시트)의 삭제·수정 원천 차단 (무결성 100% 보장)
2. **실시간 전화 상담 메모 저장 박스 신설**:
   - 상담 고객 선택 시 `전화상담일시`, `성명`, `카드번호`, `전화번호` 자동 채움
   - 통화 내용 메모 입력 후 [상담기록 저장] 클릭 시 `SBO-상담일지` DB 시트로 즉시 기록
3. **AI 자연어 일정 및 진료병원 자동 추출 (F열, G열)**:
   - 상담 메모 내용을 실시간 분석하여 약속 일정이 있으면 **`(AI) 약속일시`**에 기록 (없으면 '없음')
   - 방문 예정 병원이 감지되면 **`(AI) 진료병원`**에 기록 (없으면 '없음')
4. **상담 타임라인 실시간 즉시 누적**:
   - 저장 즉시 고객의 여정 타임라인 최상단에 `[상담일지]` 카드가 실시간 추가되어 전 직원이 바로 공유 가능
