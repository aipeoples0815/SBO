# SBO v2.0 통합 고객 상담 조회 & 치과 전용DB 연동 시스템

SBO 메인 DB(안과, 한마음카드, 백내장)와 **치과 전용 메인DB(덕천·서면점)**를 100% 통합 연동한 v2.0 업그레이드 버전입니다.

---

## 🚀 v2.0 신규 업데이트 내역
1. **치과 전용 메인DB(150명 상세 임상기록) 100% 결합**:
   - 지점별 구분(덕천점 / 서면점)
   - 세부 진료 항목(임플란트, 부분틀니, 완전틀니, 임시틀니, 치아교정 등)
   - 결제 금액 분석(첫 결제금액, 총 결제금액, 한마음 바우처 적용액, 비급여 금액)
2. **치과 전용 심층 케어 허브(Dental Hub) 위젯 신설**:
   - 고객 상세 화면에 치과 진료 요약 배너 자동 표출
3. **치과 진료 타임라인 시각화**:
   - 치과 내원, 진료, 수술, 바우처 결제 이력을 청록색(Teal) 노드로 구분하여 타임라인 표시
4. **상담 브리핑 복사 기능 강화**:
   - 치과 지점 및 치료 항목, 총 결제금액이 브리핑 양식에 자동 포함
